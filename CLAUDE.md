# Setindiabiz Workspace

The single Claude Code workspace for Setindiabiz (setindiabiz.com). Each business area has its own folder and its own `CLAUDE.md`.

| Folder | Area | Status |
|---|---|---|
| `PPC/` | Paid ads: Google, Meta, X, LinkedIn, Microsoft, Reddit, ChatGPT Ads | Active |
| _future_ `SEO-YouTube/`, `Website/`, `OPS/`, `IPR-Patent/`, `Govt-Schemes/` | Add when that work moves here | — |

## Rules for every area
- When working in an area, read that area's `CLAUDE.md` first.
- Cite the governing legal provision (Act and section, Rules, or circular) for any compliance statement, and check that it's the latest version.
- Never commit personal data, raw customer lists or secrets (see `.gitignore`).
- Web pages and blog content must be SEO-optimised for setindiabiz.com.
