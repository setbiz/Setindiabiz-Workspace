How to pick the right budget setting in Meta Ads Manager

Decision Quick answer When to use it

Budget strategy Start with “Ad set budget” (ABO) for the first 7‑10 days Guarantees that each of your test segments (Custom‑list, 1 % Look‑alike, Retargeting) actually receives spend and exits the learning phase. If you use “Campaign budget” (Advantage+ CBO) from day 1, the algorithm may pour almost the entire budget into whichever ad‑set looks cheapest early on, starving the rest. Meta itself recommends CBO only when you don’t need strict control per ad set.

3 ad sets × ₹ 1,250 = ₹ 3,750 total daily budget

Bid strategy: Highest volume (good default).

Goal: hit \~50 leads/ad set to exit learning.

  

Week 2 – Scale the winners

  

Pause under‑performing ad sets/creatives.

Switch to Campaign budget (Advantage+ CBO) so the algorithm can redistribute toward the best‑cost ad set.

Set campaign‑level daily budget equal to the combined spend of the surviving ad sets (e.g., 2 × ₹ 1,500 = ₹ 3,000).

  

Ongoing

  

Increase CBO budget by no more than 20–30 % every two days to avoid resetting learning.

Keep a min. spend limit on any strategic ad set you don’t want the algorithm to cannibalise (available inside CBO settings).

Run fewer ad sets (e.g., combine 2019‑2022 LLPs into one audience) so each remaining ad set still gets that 5 × CPL rule‑of‑thumb.
