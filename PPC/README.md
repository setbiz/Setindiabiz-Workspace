# PPC — Setindiabiz

Single workspace for all of Setindiabiz's paid ads: Google Ads, Meta, X, LinkedIn, Microsoft Ads, Reddit and ChatGPT Ads.

- `CLAUDE.md`: rules and context Claude follows
- `shared/`: business context, KPIs, budget, brand voice, landing pages and learnings
- `<platform>/`: campaigns, creatives, audiences (notes only, no raw lists), reports and changelog
- `reports/`: weekly and cross-platform reports
- `imports/`: past ChatGPT and Cowork work being migrated
- `scripts/`: reusable tools (e.g. `import_chatgpt_export.py`)
- `docs/migration-checklist.md`: start here
